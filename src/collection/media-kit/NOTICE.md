# MediaKit

Vendored from [SongJohnHannah/media-kit](https://github.com/SongJohnHannah/media-kit), version 1.1.0, under its declared MIT license. Source hashes are in manifest.json.

Switch Notion disables automatic compression, legacy ASR, plaintext cookie caching, unrelated-tab cleanup and browser termination. It adds native PATH lookup, per-request cookie files and macOS visible browser support. Regenerate with `node scripts/vendor-media-kit.mjs /path/to/media-kit`.
