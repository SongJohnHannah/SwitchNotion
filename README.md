# NotionSwitch

在 Notion 桌面版的原生 AI 界面中使用自己的 DeepSeek API Key，支持当前页面上下文、跨页面操作和多个已授权工作区。应用显示名为 Switch Notion，复用 Notion 图标。Windows 已实测；用户已确认现有 M1 Mac 版本可正常使用，新增能力的验证边界见下方覆盖文档。

项目通过本机隔离副本和协议适配器接入 DeepSeek。原版 Notion 安装保持原样，Notion 页面内容通过官方 API 读取和修改。本项目是独立原型，与 Notion、DeepSeek 官方没有隶属关系。

## 功能

- 保留页面右下角原生 AI 入口、侧栏对话、流式回复、停止和续聊。
- 在原生模型菜单切换已接入的 DeepSeek Flash / Pro，并在配置中设置思考模式和多 Agent 协同。
- 侧栏个人 Agent 可选启用公开网页阅读及 Brave Search，在配置的 DeepSeek 页保存联网开关和搜索密钥；支持来源链接、长文分页、停止与续问。默认关闭，搜索需独立密钥；交互式浏览器仍待接入。见 [联网来源接口](docs/WEB-SOURCES-INTERFACE.md)。
- 原生 Research Mode 已接通明确“仅网页”的报告、来源、本地历史、停止及重启续问；工作区页面/数据库及全部来源研究仍等待正文接入授权。见 [研究模式范围](docs/NATIVE-RESEARCH-INTERFACE.md)。
- 自动识别当前页面和工作区，支持“总结此页面”“修改当前页”。
- 搜索和读取已授权页面，创建、修改、移动和归档页面，操作内容块、表格、数据库及相关内容工具。
- 在配置界面添加多个工作区连接，只需名称和 API Key；工作区标识自动识别。
- 本机保存历史对话、任务进度和写入核验记录，支持上下文压缩和自动续跑。
- 支持选区引用和原生浮动 AI 编辑预览；浮动框可读取附加页面、表格、数据库属性及截断文字范围，引用随原生历史恢复。尚未支持的附件正文会明确提示。
- 新版页面内 Writer 已接入 DeepSeek 的续写、润色、改写、翻译、摘要、自定义文字编辑和原生撤销。支持同一父级连续文字选区/段落，保留选区外文字、段落属性和格式映射；保存前复核正文与权限。重复操作/回包丢失只核对结果，撤销不会覆盖检测到的后续修改。支持范围及其余 AI 缺口见 [检查记录](docs/AI-INTEGRATION-AUDIT.md)。
- 支持引用 AI 回复片段，并在历史恢复和上下文整理后保留；引用类型、实际验收结果及尚未对接的 AI 功能见 [引用与 AI 功能覆盖](docs/AI-REFERENCE-COVERAGE.md)。
- 原生 AI block 支持摘要、关键要点和自定义输出；可明确选择同一工作区的页面或数据库，读取记录属性和自身正文，生成后复核来源及权限。数据库范围不会冒充当前筛选视图；搜索和外部连接器尚未接入。见 [来源接口](docs/NATIVE-AI-BLOCK-INTERFACE.md)。
- 独立公式编辑器已接入 DeepSeek 生成/修复预览，使用字段结构与编译错误，不发送样本行；保留原生校验和用户确认保存流程。协议与验收边界见 [公式接口](docs/NATIVE-FORMULA-INTERFACE.md)。
- 原生基础 Autofill 的所选记录及最多 200 条的完整筛选视图可使用本地生成、受限字段写回与核验、任务进度及单行停止；其余字段/工作流类型仍待接入，真实服务器/桌面控件仍需验收。见 [Autofill 接口](docs/NATIVE-AUTOFILL-INTERFACE.md)。
- 整个普通表格、数据库或记录的选区即使没有文字预览，也能保留引用并读取对应行、字段和记录；记录选区不会自动扩展为整库。视图筛选信息无法确认时会说明范围。
- Flash 支持图片输入，Windows 与 Apple Silicon Mac 共用本地图片上传、聊天缩略图和预览逻辑；已有对话中的图片引用会恢复为可显示附件。两种分发包均有图片链路测试，Windows 桌面界面仍需实机复核。
- 原生侧栏聊天可解析主动上传的文字型 PDF、DOCX、XLSX、TXT/Markdown、CSV/TSV 和 JSON，并供同账号/工作区/对话的续问使用。Flash/Pro 均可读取文档文字；扫描 OCR、旧版 DOC/XLS 和音视频理解仍待实现。[支持范围与验收](docs/NATIVE-DOCUMENTS-INTERFACE.md)。
- 浮动 AI 框也已接入支持文档的本地上传、处理回执、文字预览和历史续问；保持原生菜单的可接受类型，不读取任意旧远程附件或 Agent 下载。实际路由与合成模型验收通过，原生窗口控件仍待复核。
- 提供 Windows 一键启动与登录同步，新增 M1 Mac 双击启动和 `.app` 分发入口、兼容版本同步和上一版本恢复。
- 独立内容收集窗口：按 `Ctrl/⌘+Shift+J`，在同一个输入框粘贴网页链接、分享文案或本地音视频路径，支持多行混合提交及逐项选择，保存到指定 Notion 数据库或父页面。
- 支持微信视频号公开分享链接；复用腾讯网页会话解析视频，并接入本地逐字稿、DeepSeek 图片／画面识别及可编辑的文章／音视频 mini skill。原始内容在前，独立 AI 输出在后；完成后的本机任务历史默认清理。详见下方用法及 [内容收集说明](docs/CONTENT-COLLECTION.md)。

跨工作区操作需要分别配置连接并给目标页面授权。默认使用当前工作区；需要跨区时明确指定工作区或要求跨工作区搜索。未授权页面无法通过连接访问。

## M1 Mac 双击启动

未压缩入口现放在项目根目录：Windows 双击 `Switch Notion.exe`，M1 Mac 双击 `Switch Notion.app`，Mac 也可用 `Switch Notion 启动.command`。入口按当前系统查找 Notion。详见 [一键启动说明](一键启动说明.md)；重新生成入口使用 `npm run prepare:launchers`，无需 ZIP。

下载源码后双击根目录的 `Switch Notion 启动.command`；配置入口为 `Switch Notion 配置.command`。Mac 分发包可双击 `SwitchNotion.app`，或把应用拖入“应用程序”后打开。首次自动查找官方 Notion，缺少运行环境时由窗口提示准备，无需输入终端命令。

现有 Mac 版本由用户确认可用，新增 AI 引用链路通过两种分发包自动测试；本次 Windows 环境未执行新增功能的 Mac 原生控件验收。尚未提供 Apple Developer ID 公证。安装、首次系统确认及本机资料位置见 [Mac 使用说明](MAC-使用说明.md)。

## Windows 使用

Windows 支持 x64。需要本机安装官方 [Notion 桌面版](https://www.notion.com/desktop)。

桌面安装、启动、更新校验和登录策略已封装到平台接口，自动按本机系统查找 Notion；接入说明见 [平台接口](docs/PLATFORM-INTERFACE.md)。

如果使用迁移包：

1. 完整解压 ZIP 到可写目录。
2. 双击 `Switch Notion.exe`（保留原入口 `NotionSwitch.exe`），自动查找已安装的 Notion。
3. 未安装时，使用准备窗口的官网入口安装，随后重新检测；也可手动选择安装位置。
4. 双击 `NotionSwitch 配置.exe`，填写 DeepSeek Key 和需要访问的工作区连接密钥。
5. 在隔离原型中登录，或在配置界面按提示同步本机 Notion 登录。
6. 从页面右下角原生 AI 入口开始使用。

换电脑需要重新登录、配置密钥并授权页面。迁移包不附带 Notion 客户端、服务额度或用户数据。详细步骤见 [Windows 使用说明](WINDOWS-使用说明.md)。

## 快捷收集到 Notion

1. 按 Windows 的 `Ctrl+Shift+J` 或 Mac 的 `⌘⇧J` 调出独立快捷框，也可从顶部“NotionSwitch → 快捷收集”、托盘或配置中的“内容收集”打开。“AI 建库”也位于顶部 NotionSwitch 菜单中。
2. 在同一个输入框粘贴来源，多个来源分行填写。支持网页／媒体链接、分享文案，以及本机音视频完整路径。
3. 选择已连接的 Notion 工作区、数据库或父页面，点击“全部收集”；需要筛选正文、图片或音视频时，使用“识别后选择”。
4. 点击主按钮右侧“提取要求”，编辑并保存文章类或音视频类 mini skill。可自动选择模板、固定模板，或选择“仅保存原文”；已开始的任务保留提交时的模板。

| 输入类型 | 示例形式 |
| --- | --- |
| 网页、图片、音视频链接 | `https://example.com/article` |
| 微信视频号公开分享链接 | `https://weixin.qq.com/sph/…` |
| 小红书图文／视频及分享文字 | `https://xhslink.cn/o/…`、`https://xhslink.com/…` 或完整笔记链接 |
| Windows 本地音视频 | `C:\Users\me\Downloads\视频.mp4` |
| Mac 本地音视频 | `/Users/me/Downloads/音频.m4a` 或 `~/Downloads/音频.m4a` |

本地路径支持空格、外层引号和 `file://` 地址，读取时不会移动或修改原文件。各网站的完整内容仍取决于实际登录、访问权限与页面适配情况。

Notion 中按以下顺序保存：**正文与对应配图 → 文末原始音视频 → 逐字稿与画面识别 → 独立 AI／Skill 输出**。正文与配图保持原有顺序，AI 总结不会替换或混入原文。逐字稿在本机生成；DeepSeek 图片／画面识别默认开启，可全局或单次关闭。

窗口关闭后继续处理。默认保留本地资料到系统的 **`Downloads / NotionSwitch / 链接标题 /`**，同名内容使用“标题 (2)”等独立文件夹。文件夹内包含原文、图片、音视频、逐字稿、画面识别、AI 提取结果和内容清单；可点击“打开下载文件夹”，或在文件管理器中整夹删除。Windows 和 Mac 均使用系统实际的下载目录，可另选位置；关闭“保留本地原始副本”后只保留处理期间的临时文件。

完成并核验后，默认清理本机任务历史和该任务的私有写入记录，Notion 与保留的下载文件夹继续存在。失败、待补全等空闲任务可点“删除任务”，一并删除该任务的下载文件夹、未完成文件与恢复记录；原始本地输入文件、网站登录资料、其他任务和已保存的 Notion 页面保留。

小红书从当前笔记提取完整正文与有序轮播图片，排除评论、头像、推荐和轮播重复图片。正文内配图保持相对位置，视频集中放在文末，再追加逐字稿、画面识别和独立 AI／Skill 输出；图片和视频上传到 Notion，不依赖原站临时外链。请保留分享链接参数。需要登录时，从“平台账号 → 小红书”打开独立收集浏览器；登录资料由浏览器持久保存，失效或遇到验证码时该条任务等待处理，其他链接继续。当前通过手动登录后点击“继续／重试”恢复，不会对每条链接自动弹出登录窗口。

小红书图文轮播与带音轨视频已在 Windows 完成真实 Notion 保存和附件读回核验。解析代码与 Mac 共用，Apple Silicon 的实际登录、下载和保存链路仍需在对应硬件验收。

“检测登录资料”会显示检测中、完成时间或失败原因；“本机有资料 · 未验证”表示浏览器保存了登录资料，实际会话仍可能失效。清理收集任务不会退出网站。

视频画面分析当前按时间均匀采样，张数为 `min(60, max(1, ceil(视频秒数 / 30)))`：约 57 秒抽 2 张，5 分钟抽 10 张，30 分钟及以上最多 60 张。采样不是重点场景识别，也不等于逐帧观看。本机抽帧不消耗模型 Token；向 DeepSeek 发送图片识别、再生成 AI／Skill 摘要会产生 API 用量。摘要会参考画面分析文字，采样截图保存在本地素材文件夹的 `frames/` 中。

视频号分享解析使用收集浏览器中的腾讯网页会话，无需运行 `wx_channel.exe`、安装微信抓取驱动或根证书。网页会话失效时，从“平台账号 → 微信视频号”打开对应腾讯网页后重试。Windows 和 Apple Silicon Mac 均有公开分享视频的下载、音轨、逐字稿、AI 输出及真实 Notion 保存核验；Mac 记录与新增功能待验收项见 [Mac 验收清单](docs/MAC-CHECKLIST-ACCEPTANCE-2026-10-29.md)。微信内置主页、评论、直播和其他私有内容不在这条分享路线的验收范围内。整个 Switch Notion 桌面版的 Linux 平台适配尚未实现。

## 从源码运行

需要 Node.js 22 或更新版本，无第三方 npm 依赖。

```powershell
git clone git@github.com:SongJohnHannah/SwitchNotion.git
cd SwitchNotion
npm run settings
```

也可以双击项目内的 `NotionSwitch 配置.vbs` 或 `NotionSwitch 启动.vbs`。源码运行时需要自行安装 Node.js；迁移包自带运行环境。

开发命令：

```powershell
npm start
npm run status
npm run stop
npm run collect
npm test
npm run check:secrets
npm run check:windows
npm run package:windows
```

Windows 迁移包构建产物保存在 `dist/`，不创建桌面文件。配置界面保存后，下一轮 AI 对话使用新设置。

`npm run check:windows` 只读检测 Windows 环境、Node、Notion 安装、隔离副本、登录辅助程序位置和离线语音配置；不会下载组件或读取 Cookie/密钥。实机验证步骤见 [Windows 验证清单](docs/WINDOWS-VALIDATION-CHECKLIST.md)。

## 密钥和本机资料

**DeepSeek Key、可选 Brave Search Key、Notion 连接密钥、登录资料和本机聊天记录只在本机保存，不提交到 Git，也不打包分发。** 调用 DeepSeek 时，Key 通过官方 HTTPS API 用于认证，不传给 Notion。选定的页面内容会作为任务上下文发送给 DeepSeek。启用联网来源后，搜索词发送到 Brave Search，读到的公开网页正文作为资料发送给 DeepSeek。

- 本机运行资料集中保存在 `.notion-switch/`；整个目录已忽略。
- `research/` 包含本机验证记录，`dist/` 包含构建产物，均不提交。
- `.env`、私人配置、密钥文件、Cookie、日志和私钥文件已加入忽略规则。
- `npm run check:secrets` 检查实际 Git 暂存内容，并与本机已配置密钥比对；发现凭据或私人文件时停止，且不输出密钥值。
- 打包使用允许清单，并额外检查凭据内容。新电脑的初始配置不包含工作区或 API Key。

不要公开复制整个使用过的项目目录；分发时使用 `npm run package:windows` 的干净产物。

## 更新与兼容

已审核 Notion 7.40.0 和 7.40.1。兼容检查目前覆盖原有接入结构的 Notion 7.x、Electron 44，以及已审核的网页模块。

原版更新后，完全退出并重新启动原型会尝试同步兼容版本。配置中的“版本与更新”提供检查、更新并重启、恢复上一版；也可使用独立的更新启动入口。更新不会自动打断正在进行的 AI 任务。

更新在项目内暂存和校验，通过本机启动检查后才确认。准备失败保留现有原型；新版本启动失败时尝试恢复上一版。登录、密钥和历史资料不参与运行目录交换。

启动检查不代表所有云端协议都兼容。Notion 网页协议或桌面接入点变化时，仍可能需要新版适配器；客户端回退也不能保证恢复云端协议。目前没有远程适配器自动发布服务。

## 页面操作边界

写入工具在本机保存核验记录。提交期间断网或停止，远端操作可能已经生效，程序会阻止盲目重复写入；停止不会撤销已提交的修改。客户端版本检查无法提供服务端事务或多人编辑锁。

本地校验失败、官方明确的参数拒绝与结果不确定的写入分别记录。明确未执行的请求不会锁住整轮其他操作；断网、服务端未知错误及写入后的读回失败仍停止后续写入。中间插入使用当前 `position` 参数，通过插入前后的块 ID、顺序和内容核验，回包中的已有相邻块不会被当成新建块。

自动测试覆盖 Agent、工具调用、凭据隔离、模型路由、流式中断、历史、选区、更新与打包等行为；真实 Notion 界面和未来网页版本仍需另行验收。浮动编辑预览已验证，应用修改及浮动框后续追问的完整验收仍有限。已接管的聊天、浮动编辑、公式与基础 Autofill 不会因本地失败而回退到 Notion 托管推理；其他原生功能仍需逐项核对，配置 DeepSeek 不等于替换所有 AI 入口。完整边界见 [对接检查记录](docs/AI-INTEGRATION-AUDIT.md)。

依赖已审核 Notion 网页缓存的兼容测试，在没有对应本机缓存时明确跳过；第三方网页代码不随本项目分发。真实 GPU 推理测试需显式启用；跳过原因和本轮结果见 [Windows 验收清单](docs/WINDOWS-VALIDATION-CHECKLIST.md)。

本机聊天记录不会同步到 Notion 云端或其他设备。模型服务目前仅接入 DeepSeek，可选搜索服务为 Brave Search。

配置的“离线语音”支持 Medium / Large-v3 Turbo 模型选择、缺失组件自动下载和直接麦克风录音测试。Windows 使用 NVIDIA CUDA FP16，M1 等 Apple Silicon Mac 使用 CPU INT8；本轮没有新增 Mac 硬件推理或真人录音验收。原生录音按片段离线识别，支持尾段收尾和去重。停止后默认把转录文字与手写笔记交给 DeepSeek，生成原生“摘要”标签并读回核验；原转录、手写笔记保留。可在配置关闭自动摘要，仅使用本机转写。`npm run package:speech` 可导出不包含模型、运行环境或用户资料的独立转写模块。详见 [跨平台转写接口](docs/SPEECH-INTERFACE.md)、[原生速记适配](docs/OFFLINE-SPEECH.md) 和 [摘要接口](docs/MEETING-SUMMARY-INTERFACE.md)。
