## 新增共用能力与读取边界

浮动框使用现有工作区 Router；读取器没有系统路径或平台分支，也不向模型提供写入工具。附加页面引用可按自己的显式工作区读取，最多 32 个去重来源；默认最多 128 次工具调用、800 块/记录、160,000 字符，超限或超时明确失败。页面 Markdown、容器子块、数据库记录及长字段继续分页；重复游标、来源变化、权限拒绝和停止均不把部分结果当成完整资料。

文字范围按原生字素位置保留表情与组合字符；跨块只输出选中范围，不扩成整页。块内页面链接/提及只保留指针，不隐式打开目标；明确附加页面才读取整页。数据库读取记录属性，不扩读每条记录正文，也不把整库结果冒充当前筛选视图。页面 PDF、音视频、网页链接和未知块保留实际字段并标注正文限制。侧栏与浮动 writer 的本地主动上传文档均已接通；浮动框旧远程附件、Agent 下载和未知来源仍在模型前明确失败。

AI block 使用当前登录账号的原生记录读取，支持最多 32 个明确选择的同工作区页面/数据库，去重并保留顺序。数据库完整读取最多 200 条活动记录的属性和自身正文；上下文没有视图 ID，结果明确标注未采用界面筛选。未选当前页正文、子页和关联/提及目标不自动展开。生成后重新核对字段结构、记录范围、配置、正文和权限。返回 Markdown 交由原生流程处理，模块本身不提交页面写入。工作区搜索、外部连接器和跨工作区来源尚未接入。
