# 工作区 MCP 连接

2026-10-28。连接在工作区 API Key 卡片的“记忆与技能 → 网页操作与 MCP 连接”中管理。Windows/Mac 使用相同的 Node 客户端和设置页，不增加安装包或平台启动脚本。

## 传输与登录

- Streamable HTTP：发送到配置的 `/mcp` 地址，支持 JSON 和 SSE 响应、会话标识和关闭会话。
- 旧版 HTTP + SSE：先 GET 用户配置的 SSE 地址，再接收服务提供的 POST 地址，通过同一个事件流接收结果。POST 地址必须同源；不跟随重定向，不自动重连或重放工具调用。
- stdio：启动明确配置的命令/参数，不使用 Shell，沿用现有受限环境。Windows 的 npx 通过所属 Node 执行；Mac 沿用命令路径与参数。
- 远程服务可手动填 Bearer Token，或保存后点击“OAuth 登录”。OAuth 在系统浏览器完成，按受保护资源元数据发现授权服务，支持公开客户端动态注册，亦可填写服务提供的 Client ID。使用 PKCE S256、随机 state、仅监听 127.0.0.1 的临时回调及 resource 绑定；三分钟超时，可在设置页取消。
- 到期令牌在调用工具前刷新，支持刷新令牌轮换。401 不重发工具，需重新登录时由用户操作。“退出 OAuth 登录”或勾选“清除服务凭据”移除本机凭据；这不替代服务商的授权撤销页面。

OAuth 支持声明 PKCE S256 的公开客户端授权服务器。需要客户端密钥、固定回调端口、企业自定义登录或客户端元数据文档的服务仍须自行提供兼容公开客户端配置；不把任何第三方登录方式都视为已支持。远程授权端点要求 HTTPS；本机合成调试仅允许与本机资源同源的 HTTP。传输选择由用户明确配置，不通过试调用切换协议。

## 资料与执行范围

服务只属于当前工作区。Bearer/OAuth 凭据只保存在本机配置中，不进入模型、工具目录或设置页返回数据；发现与注册请求不会附带现有服务令牌。OAuth 凭据不能转移到其他 URL。登录取消、服务移除或修改时，不保存旧登录结果；退出登录使正在运行的任务失效。

模型先读取目录，再调用当前定义未改变的工具。每次 MCP 执行仍显示服务、工具和实际参数确认框。已提交但结果未知的操作只提示核对，不自动重放；持久记录防止同任务重复提交。服务请求 sampling、roots 或其他客户端交互时返回“不支持”，不隐式开放本机目录或模型。

## 验证

Windows 本机真实 HTTP 合成服务验证旧 SSE 握手、分段 CRLF、工具目录/单次执行、跨源地址拒绝、断线、超时与停止；OAuth 合成授权服务器验证发现、自动注册、错误 state、PKCE、resource、令牌刷新/轮换、取消、本机保存、设置页凭据过滤及退出后任务失效。实际设置页在隔离 Edge 中验证传输选择、保存、登录和取消；27 项相关既有回归通过。未新增永久测试文件、未读取业务 MCP 服务、未调用真实第三方 OAuth。Mac 拉取后按 N22 验收。
