# 本地 AI 对话共享与迁移

2026-10-28。第 23 项包含两个用途，入口位于 **配置 → 工作区 API Key 卡片 → 记忆与技能 → 对话共享、导出与导入**。

## 只读共享

选择一条已停止生成的侧栏、浮动或研究对话，点击“共享所选对话为只读 HTML”，在系统保存窗口选择位置。生成的单个 HTML 文件可在 Windows/Mac 浏览器直接打开，按消息顺序展示提问、AI 文字和可选的引用资料；页面是导出时的快照，查看不会调用模型、访问 Notion 或执行消息里的代码。

查看密码可留空；留空时，持有文件的人都能阅读。设置密码须为 8–128 个字符，导出内容使用随机盐、PBKDF2-SHA256（250,000 次）及 AES-256-GCM 加密，浏览器使用 WebCrypto 解锁。错误密码不展示内容。密码只用于本次导出，不保存在配置和 HTML 中，保存返回后输入框清空。加密文件的标题、消息和引用均在密文内。两种文件均由严格 CSP 限制，不加载外部脚本、字体、图片或网络资源；消息仅作文字显示。

“包含当时的引用资料”默认关闭，勾选后加入相应引用文字或标识，展开可读。配置中的 API Key、Cookie、工作区记忆/技能、工具授权、待执行操作及原始附件不进入 HTML；用户曾在对话中主动输入的内容会随文字保存。导出不创建团队账号或云端共享链接。文件和密码由用户自行传递；文件发出后无法远程撤回，也不支持多人继续编辑这一份快照。

`AiTransfer` 根据当前工作区记忆卡片的归属检查对话，拒绝其他工作区及正在生成的对话；侧栏和浮动记录同 ID 时仍分别核对所有者。保存路径来自系统窗口，拒绝目录/符号链接等非普通 HTML 目标。`chat-share.cjs` 只序列化标题、时间和选定消息，不把整个线程或配置对象写入文件。

## 同账号迁移

原来的 JSON 对话/记忆导入导出继续用于自己的 Windows、Mac 之间迁移，同一账号和工作区校验保留。引用作为资料恢复，导入不自动调用模型或执行页面操作。原始附件需在目标电脑重新上传，密钥继续在本机配置。

单份 JSON 导入上限由 1 MiB 调整为 2 MiB，与既有 500 条消息、500,000 个 JSON 字符和记忆/技能各自限额配合。此前合法的较长中文文本可能因 UTF-8 超过 1 MiB 而无法导回；现已用超过 1 MiB 的合成中文对话完整往返验证。

## Windows 结果与 Mac 验收

临时合成检查通过当前工作区隔离、生成中拒绝、取消零写入、可选引用、配置/附件排除、特殊 HTML 文字、独立 Node 解密、本地浏览器错误/正确密码、Unicode WebCrypto、深色显示、零网络请求及配置页到 SettingsService 的实际调用。37 项既有设置、Agent、引用和研究回归通过；无真实 Notion/模型请求。私有证据为 `chat-share-result.json` 和 `chat-share-regression.log`，没有新增永久测试文件。

实现使用共用 Node/Electron 和浏览器接口，Mac 原有启动、登录、签名、音频代码保持原样；不打包。Mac 拉取 main 并重开后按 N17 测试，尤其核对默认浏览器的本地加密文件解锁。
