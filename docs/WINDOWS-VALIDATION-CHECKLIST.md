## Windows 接手顺序

1. 先检查工作区并保存既有源码修改，再更新源码并记录实际提交号；保留本机 `.notion-switch` 配置、登录和历史，不用强制重置覆盖本机工作；不要复制 Mac 的 Cookie、密钥或运行目录。
2. 完成 `ENV`，优先验收 `REF/IMG/MEET`，修复已有功能的失败项；随后核对 `PAGE/PKG`。
3. 再按下方顺序实现 `AI` 待办。每项完成后补原生入口适配、模型/工具链路、失败提示、停止/恢复及适用的自动测试；不能只让模型用文字宣称功能已完成。
4. 每批修改提交代码和逐项结果，保留未完成任务，说明 Mac 共用逻辑的影响。接口和数据处理尽量共用，系统差异放入平台适配层。

完整的能力边界与 Mac 证据见 [AI 引用验收与功能对接范围](AI-REFERENCE-COVERAGE.md)。本清单不要求修改既有启动文件名称。
