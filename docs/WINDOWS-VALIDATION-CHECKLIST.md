## P0：原生会议录音、停止和摘要指令

- [ ] **MEET-01 启动转写**：在新建的原生会议中点击 Start transcribing，按 Windows 系统提示处理麦克风授权。通过标准：成功开始，界面和系统录音状态一致，不再出现 “Unable to start transcription”；配置状态中的录音模块适配已就绪。
- [ ] **MEET-02 两种音源**：分别测试仅麦克风、麦克风加系统音频，朗读可核对的中英文短句。通过标准：所选音源产生对应转录；关闭的音源不被采集；没有明显重复片段。注明硬件、模型与实际延迟。
- [ ] **MEET-03 停止尾句和连续两次录音**：说完最后一句立刻停止，再开始第二次录音。通过标准：点击停止后释放采集；检查最后短句是否完整、是否重复；第二次能正常开始，第一场迟到结果不会进入第二场。若触发超时，保留耗时和提示，不能通过无限延长停止等待解决。
- [ ] **MEET-04 自动摘要开关**：分别开启、关闭“停止录音后用 DeepSeek 自动生成摘要”，录音并停止。通过标准：开启时生成原生“摘要”标签；关闭时仅保留转录，不报 HTTP 503；原手写笔记和转录不被覆盖。
- [ ] **MEET-05 预设与自定义指令**：对同一段测试转录分别选择 Auto、候选人面试、客户会议、站立会议，再选择自行编辑的指令页。通过标准：结果结构和关注点随选择变化；自定义要求确实生效；重新打开仍保留选择，明确选 Auto 能覆盖此前模板。
- [ ] **MEET-06 模板访问和改动**：测试可访问的另一工作区模板，以及不可访问或空的模板。通过标准：前者正常使用且摘要仍写到原会议；后者明确失败，不静默退回 Auto。生成期间修改模板时，不写入使用旧指令生成的结果。

主要代码：`src/speech/`、`src/meeting-audio.cjs`、`src/compat/`、`src/meeting-summary-instructions.cjs`、`src/meeting-summary*.cjs`。协议和停止边界见 [原生速记](OFFLINE-SPEECH.md)、[摘要指令](AI-MEETING-NOTES-INTERFACE.md)。
