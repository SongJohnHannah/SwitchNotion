# 快捷收集到 Notion

快捷收集是 Switch Notion 的独立窗口。默认使用 `Ctrl+Shift+J`（Windows）或 `⌘⇧J`（Apple Silicon Mac）调出，也可从托盘／菜单栏打开。快捷键可更换；冲突时保留托盘入口并显示原因。

## 使用

1. 在配置中心的“内容收集”打开收集窗口。展开后选择工作区，搜索数据库或父页面，也可粘贴 Notion 链接；常用位置可以收藏并设为默认。
2. 需要新库时，选择一个已授权父页面，点击“在所选父页面下新建收集库”。创建标题、来源链接、内容类型、来源网站、收集时间、处理状态和标签字段，不更改已有数据库的结构。
3. 在“平台账号”打开网站登录。默认使用独立浏览器资料；高级设置可以选择以前 media-kit 的独立资料目录来复用登录，不需要将 Cookie 或密码粘贴到聊天中。
4. 同一个输入框支持网页链接、分享文案和本地音视频路径，可多行混合提交。Windows 可粘贴 `C:\Users\me\Downloads\视频.mp4`，Mac 可输入 `/Users/me/Downloads/音频.m4a` 或 `~/Downloads/音频.m4a`，也支持 `file:///…` 和带空格的引号路径。本地文件复制到临时工作区处理，不移动或修改原文件；重试会核对文件是否改变。
5. 主按钮右侧“提取要求”打开文章类、音视频类两套 mini skill。可修改、保存或恢复内置模板，自动按内容选择，也可固定模板或关闭提取。正文、逐字稿与已开启的画面分析会交给 DeepSeek，原始内容先保留，AI / Skill 输出单独追加在页面最后。已开始的处理使用提交时冻结的模板。
6. 收起／关闭收集窗口后继续运行。已完成的本机历史默认不保留，到 Notion 查看结果；仅处理中和待补全内容保留进度。可在展开选项中主动开启本机完成历史。关闭开关会清理已有完成记录，但保留 Notion 内容和主动导出的本地副本。

## 内容处理

- 正文按标题、段落、引用、列表、代码和链接的语义顺序保存，配图保持对应位置。文章附带的音视频集中在文末“原始音视频”，随后是逐字稿与画面识别，再单独追加 AI / Skill 输出；不将 AI 总结插入原文。适配 Notion 块式排版，不承诺网页像素级复刻。
- 图片优先取原图或最高分辨率候选，文章图片上传为 Notion 文件，避免依赖会过期的原站外链。下载失败的媒体保留原位置占位，重试后在原位置补全；不会清空用户追加的其他内容。
- 视频可以按 720p、1080p 或原始分辨率压缩。已达到所选画质且码率较低时保留原文件；重编码前后核对时长。超过工作区单文件上限时按时间顺序分段，不截掉尾部。图片超过工作区附件上限时保留本地原图并报告待补全，不静默降低原图分辨率。
- 视频和音频复用本机离线语音引擎，以 10 秒输入分段转写，每分钟保存进度，不翻译或润色原话。本机进程退出时恢复当前段，重试复用已完成分钟。Windows 优先使用 NVIDIA；连续异常时用相同模型在本机 CPU 离线补全，注明回退原因。Apple Silicon 使用原生 ARM64 CPU INT8 后端。
- 抖音等平台的画面与音轨可能分开传输。收集器会合并独立音轨并核对时长；原站已观察到音轨而下载结果缺音轨时，显示待补全。MKV 等下载封装先无损转为 MP4，再上传到 Notion。
- DeepSeek 图片／视频画面识别默认开启，可在配置中心修改全局默认，也可只改变本次任务。复用现有 Key，使用 Flash 图片模型；图片或视频关键帧发送到官方 API。音频逐字稿和画面分析放在独立附录，不混入原文。
- 视频画面分析按时长抽取最多 60 张关键帧，明确标注采样范围；不宣称逐帧观看完整视频。
- 有登录资料不等于登录仍有效。登录墙、预览、验证码、内容不可用和加载失败应显示未完成；用户可以登录后重新读取，或明确选择保存已取得的部分。

## 后台、文件与恢复

- 设置、已保存模板和未完成进度位于本机状态目录的 `collection/`。默认在成功核验后移除完成任务、原文快照、临时媒体和该任务对应写入记录；当前会话只留有限的轻量回执用于打开 Notion、防止重复点击，不写入历史。提交时冻结处理选项，修改默认不会改变在途任务。
- 下载、转写、识别、上传和页面写入分别保存检查点。停止不撤销已提交的 Notion 写入；结果不确定时核验并停止重复提交。
- 同一个来源、目标和处理选项默认复用已有任务；失败任务继续原进度。明确点击“重新收集为新记录”才创建新的同源记录。
- 启用“保留本地原始副本”时，导出原始文件和有顺序的内容／识别清单。完整归档且未要求本地副本时清理工作缓存；未完成任务保留原文件供重试。
- 登录由 Chrome／Edge／Brave 自己保存。media-kit 的旧明文 Cookie 磁盘缓存已停用；下载器必需的临时 Cookie 文件位于本任务内，退出或取消后清理。Cookie 不进入 Notion、DeepSeek、界面返回或分发包。
- 分发代码包含固定 media-kit 运行快照，无需安装 OpenClaw 或启动 MCP 服务。缺失的 yt-dlp、FFmpeg 可通过“检测并准备”下载，校验固定 SHA-256；不打包本机模型、登录或下载记录。

## 开发验证

```text
node --test tests/collection-*.test.mjs
node scripts/check-collection-ui.mjs
node scripts/check-collection-electron.mjs
node scripts/check-collection-media.mjs --speech --vision
node scripts/check-collection-media.mjs --speech --extraction
npm test
npm run package:windows
npm run package:mac
```

界面／浏览器验证脚本使用开发机安装的 playwright-core 和 Chrome。Electron 验证脚本使用项目的 Windows 隔离运行目录，另建空白资料和离屏窗口，不使用用户的 Notion 登录。媒体验证使用生成的测试图、视频和语音；`--vision` 会实际调用已配置的 DeepSeek。

真实链接验收读取忽略目录中的 `.local.json` 输入，避免将用户的链接和账号信息写入源码。网站结构可能变化；命名平台的登录、付费／会员权限和地区可用性以实际账户和网站返回为准。Apple Silicon 的原生启动、全局快捷键、登录与完整收集链路需要在对应硬件上验收。
