# AI 操作确认与等待状态

2026-10-28。页面/API 修改、MCP 工具、网页点击/填写及日历写入沿用实际执行前的原生确认窗口。页面修改可按每轮工作区确认或每项确认；MCP、网页及日历各自显示实际操作内容，不受页面资料中的指令绕过。

共用审批状态现覆盖上述 Agent 服务：真正弹出确认前才进入 `awaiting_approval`，聊天显示“等待你确认”，本机后台任务显示需要确认并通知。用户允许后才恢复执行；拒绝和停止显示取消状态，不因模型继续回复而视为批准。此前同轮已批准的页面范围不会再显示一次虚假的等待。

确认只代表允许本次执行，成功仍由原工具的读回/回执判断。取消当前确认不会声称撤销此前已经提交的修改。停止信号贯穿原生确认；已经提交但结果未知的请求继续按原日志/恢复规则处理，不能靠重新确认重复提交。

本实现使用 Notion 内的文字进度和 Electron 原生确认窗口，没有增加新网页控件、伪造未知原生工具卡片协议或永久免确认开关。建库的字段预览和完成创建继续使用其自身已接入的原生确认。Windows/Mac 共享审批状态和代码，平台启动、登录、签名及采集模块未改。

Windows 合成链路核对实际 Agent 的 MCP 等待、允许后单次执行、拒绝零执行；日历的现有十组检查仍通过，包括拒绝、版本变化、未知结果与重启防重。89 项相关既有回归通过。未新增永久测试文件，Mac 原生窗口由用户按 N24 验收。
