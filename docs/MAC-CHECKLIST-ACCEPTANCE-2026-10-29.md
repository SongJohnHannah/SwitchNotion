# Mac 清单复验（2026-10-29）

环境：Apple Silicon arm64，macOS 26.6，Notion 7.41.0 / Electron 44.9.1。已合并截至 `161816c` 的新功能，沿用现有隔离资料目录和连接。只使用合成内容及用户提供的视频号测试来源；本记录不包含账号标识、密钥、下载令牌或业务正文。

## 本轮修复

- **生成文件下载**：Mac 原生聊天将下载地址中的 UUID 识别成页面链接。Mac 专用服务改用无 UUID 的可逆地址编码，点击时通过现有本机协议读取文件并触发 Blob 下载。原有令牌、账号/工作区、请求方式、文件哈希检查继续生效。Windows 使用原有服务。旧聊天中已变成页面链接的地址需重新生成。
- **更新目录清理**：实机回退后，待清理目录只剩 Finder 重新写入的 `.DS_Store`，使 `rmdir` 报 `ENOTEMPTY`。仅 Darwin 分支有限重试，最多等待 500 ms；其他错误仍立即报出。目录边界、签名、完整性和回退规则保持原样。
- **录音资源更新**：新增精确审核的 `89269-0cf389326d6293f8.js`。与已审核版本的 34 个模块比较，录音控制器 331787、音频录制器 392719 字节一致；仅 315368、212680 的懒加载依赖变化。继续拒绝未知字节，Windows 不加载这项 Mac 适配。

## 验证结果

最新非打包源码回归：106 个测试文件，688 项中 **671 通过、16 跳过、1 失败**。唯一失败仍是既有 `web-agent.test.mjs` 夹具缺少当前指令/会议桥 mock，没有修改共用夹具掩盖结果。沙箱内另有 `fs.watch` 的 `EMFILE`，在原生权限下复跑后消失。上述全量回归在目录清理和新录音资源补丁前执行；最终 Mac、更新、Windows 分支隔离及视频号专项共 **44 项：42 通过、2 跳过、0 失败**。

原生聊天实际生成、点击并保存三份文件到下载目录：XLSX 2,466 字节、PDF 10,972 字节、PPTX 9,874 字节。下载后逐份核对 SHA-256，并用独立 openpyxl、pypdf、python-pptx 读取，均含中文“合成927”和数字 927。PDF 使用实际 Electron 打印引擎。

真实本机协议补验四组通过：逐字段只填空白、人员唯一/同名/成员变化校验、旧版 SSE 握手及同源 POST 限制、OAuth 回环/PKCE/错误 state/刷新/取消。均使用隔离合成服务，不代表真实第三方账号已连接。

最终正常退出并通过项目启动检查，427 份运行源码与项目一致，活动任务为 0，前端未适配资源为 0。此前锁屏期间曾出现主窗口初始化停滞、页面加载超时；没有通过延长超时或取消启动验证掩盖它。

## 新增视频号功能

已在 Mac 原生快捷收集窗口核对“微信视频号”入口，使用用户提供的分享链接，保存位置选择专用 Notion 测试父页。首次任务进入队列后明确失败：`收集链接解析到了本机、内网或保留地址。`，当时没有创建页面。

复核发现 GitHub、微信分享、元宝、视频号域名均解析为代理的 `198.18.x.x` 假 IP。仅 Mac 增加 HTTPS DNS 回退：只有全部本机结果属于该假 IP 段时，向固定 Cloudflare HTTPS DNS 端点查询公开域名的 A 记录，检查问题及 CNAME 链，再交给原有公网地址校验。实际下载固定到校验后的地址，Mac 的代理 CONNECT 也固定地址并保留原 TLS 主机名；不修改系统代理/DNS、不放行保留地址。缓存遵守 DNS TTL 且最多 30 秒。Windows 保留原来的解析器及 CONNECT 行为，不加载 Mac 模块。

补丁后实际下载并通过 SHA-256 校验的 Mac 下载器、FFmpeg 均已就绪。同一分享链接在原生界面解析出正文、封面和视频，选择保存后完整链路成功：

| 实测内容 | 结果 |
| --- | --- |
| 原始视频下载及本地副本 | 1,558,315 字节、10.6 秒，含视频及音轨；导出副本与下载原件 SHA-256 相同，整段解码通过 |
| 离线转写和提取 | 本机逐字稿 81 字，已配置模型的提取结果 895 字；正文与 AI 输出分别保存 |
| Notion 保存及独立读回 | 专用测试父页下生成 42 个块；重新读取实际文件并下载，1,522,536 字节、10.61 秒，音轨存在，整段解码通过；原始标题、媒体顺序、AI 提取章节可见 |
| 完成清理 | 原生界面显示“打开刚保存的 Notion”；临时任务已清理，用户选择保留的本地原始副本仍在下载目录 |
| 追加回归 | Mac DNS/采集/附件/录音专项 59 项全部通过；完整非打包回归 107 个文件、694 项中 677 通过、16 跳过、1 个上述既有 `web-agent` 夹具失败 |

只在同一个 `main` 分支工作。本次实测通过的是用户提供的这一条公开分享，不能保证所有私有、过期或需要额外权限的视频均可下载。详细记录保存在忽略目录 `wechat-download-final-result.local.json`、`wechat-mac-dns-regression.log`、`wechat-final-source-tests.log`，不提交真实链接、媒体或签名地址。
