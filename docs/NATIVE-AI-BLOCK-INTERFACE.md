## 入口与来源

原生 `generateAiBlock` 请求指定 AI block 和父页面指针。本地使用同一原生登录账号读取块配置、核对父级链和编辑权限，再读取 `ai_block_configuration_menu.context` 中明确选择的来源。支持当前页、指定同工作区页面和同工作区数据库。返回 NDJSON 的 `markdownString`，由原生客户端处理结果；本模块不提交页面写入。

数据库来源的原生配置是 `{type:"collection",pageId,collectionId}`，没有视图 ID。该结构见官方公开 [配置迁移模块](https://app.notion.com/_assets/22194-625f5aaea2cefe74.js) 与 [引用复制模块](https://app.notion.com/_assets/60921-b07cc86868b9911a.js)。查询按 [原生集合查询辅助模块](https://app.notion.com/_assets/70785-ca5edbbac4f047aa.js) 的方式提供原生视图指针和显式 loader；未提供筛选/排序时读取活动数据库记录，不能称为当前界面的筛选结果。

数据库读取过程：

1. 核对所选数据库块、collection 指针和工作区，读取字段结构；验证原生视图归属。
2. 使用原生 `queryCollection` 从头读取全部非归档记录。结果必须明确 `hasMore:false`，无重复且不超过 200 条；不完整或超限则在模型调用前失败。
3. 读取记录的全部属性和记录自身正文；子页面、链接、关联与提及仅保留可用的标题/指针，不自动打开目标。
4. 来源 JSON 包含字段名称/类型/选项、记录属性的文字与原生值、正文，以及媒体 `body_available:false` 标记。`scope` 明确指出完整数据库范围、未应用视图筛选及未展开子页。
5. 生成后复核字段结构、来源配置、块权限与内容，并重查记录成员；变化时拒绝返回过期结果。

页面与数据库可混合引用，按选择顺序处理；相同页面或同一数据库去重。未选择的当前页正文不读取。空数据库保留字段结构并明确记录为空，不编造记录。

## 边界与失败行为

- 最多 32 个显式来源、每库 200 条完整活动记录、合计 800 个来源记录、160,000 字符的模型来源资料、4,000,000 字符的核对快照和 1,024 次只读调用。超限时明确失败，不将截断资料交给模型。
- 来源页/数据库需要读取权限，AI block 需要编辑权限；生成结束重新检查。跨工作区来源、工作区搜索、外部连接器和未知视图范围尚未接入。
- 媒体链接、说明与原始值不是附件正文。PDF、图片、音视频、网页嵌入和未知媒体未在此接口解析；模型被明确告知不得声称已经识别或浏览。
- 全部 I/O 通过现有原生账号/工作区会话。新增数据库读取器只调用 `getRecordValues` 和 `queryCollection`；模型没有工具，不执行写入。来源资料仅供本次生成和复核，不新增持久化存储。
- 复核不是服务端编辑锁；检查之后仍可能发生并发修改。原生客户端的后续应用行为需要独立验收。

## 验证结果

- 原有 9 项页面 AI block 测试继续通过；新增 9 项数据库测试覆盖字段/属性/正文、完整范围、混合引用、去重、只读权限、未展开子页/关联、范围与字段变化、权限撤回、空库、停止、容量限制和实际 desktop route。
- 两种实际暂存包加载包内 AI block 及数据库读取器，验证选定页面和数据库资料进入模型；18 项 AI block 测试与两种包内测试合计 20 项通过。该结果不等同 Mac 硬件或原生窗口实测。
- 真实 DeepSeek 通过实际 desktop route 验收一次：3 条新生成的内存合成记录、14 次内存原生读取（含两次范围查询）、0 次托管生成、0 次真实 Notion 修改，未选当前页排除，未解析媒体未被声称已读。
- 仍待真实服务器数据库查询和 Windows/Mac 新增原生控件验收；搜索、连接器、跨工作区来源及通用附件正文仍未完成。项目整体范围见 [AI 对接检查](AI-INTEGRATION-AUDIT.md)。
