# 原生聊天文档附件接口

**文件属性补齐（2026-10-28）：** 数据库记录的“文件与媒体”属性也接入附件正文。`read_notion_file` 支持两种互斥定位：正文附件的 `block_id`，或文件属性的 `page_id + property_id + file_index`（序号从零开始）。字段 ID、文件名和顺序来自实际 `read_database_entry`；只下载选定文件，不接受模型提供下载 URL。复用[官方记录属性读取接口](https://developers.notion.com/reference/retrieve-a-page-property)和[files 数据结构](https://developers.notion.com/reference/page-property-values#files)，没有再造数据读写 API。

浮动引用和研究明确引用某条记录时，自动读取该记录文件属性；仅引用整个数据库的属性列表时，不顺带下载所有记录附件。原生 AI 区块对其明确选择的记录检测文件字段，再通过该工作区已配置且获授权的 API 连接读取属性附件；正文附件继续使用原生会话签名，无需额外连接。解析复用文档、mediaocr 与音轨转写器，正文块和文件属性共享每轮 8 个/24 MiB 上限。

下载和解析后核对文件名、顺序、字段及稳定文件地址；Notion 托管地址仅刷新签名不误报文件替换。替换/移除/重排、无权限、回收站或解析途中变化均拒绝旧结果。模型的数据库记录/属性/查询工具结果只保留文件名、序号和未读标记，签名地址留在下载器内；引用及 AI 区块同样只发送解析正文和来源标识。文件内容保持资料属性，不作为命令。

Windows 用实际数据库 API 适配器和文档解析线程完成合成检查，覆盖编码字段 ID、签名刷新、替换拒绝、共享预算、未知格式、浮动/研究引用和原生 AI 区块；没有真实页面修改或模型请求。最终附件相关回归 127 项、Agent/研究检查 57 项全部通过（两组有重叠），见私有 `file-properties-final-regression.log`、`file-properties-runtime-regression.log` 和 `file-properties-result.json`；Mac 步骤为 N16。不新增永久测试文件、不打包、不修改 Mac 平台运行/登录/音频代码。

**追加能力（2026-10-28）：** 侧栏/浮动本地附件可接入 `media-transcript.cjs`，对 MP3/M4A/AAC/WAV/FLAC/OGG/OPUS、MP4/MOV/MKV/WebM 音轨离线生成原话逐字稿；聊天上传保留 16 MB 单文件和 24 MB 合计限制。配置页“离线语音”另有大文件选择、媒体组件准备、进度、停止与 TXT 保存，单文件不超过 2 GB/四小时，原文件只读，工作副本在私有资料目录处理。复用既有语音/媒体组件，不修改 Mac 音频平台实现，不分析视频画面。新生成的合成 WAV/MP4 已通过真实本机 CPU 转写，均包含代码 927，未调用外部模型。

`page-files.cjs` 提供当前工作区已授权附件块的 `read_notion_file`，现在接入侧栏/本地后台、原生研究和浮动引用。浮动框及研究明确引用页面时会遍历本页内容块并解析支持的附件，不展开子页面、数据库或同步来源；直接引用附件同样可读。每轮最多 8 个/24 MiB，单文件最多 16 MiB，读取失败不把元数据当正文。附件下载不带 Notion Cookie/密钥，限制公网解析、跳转和大小；下载后及解析后分别复核版本，多来源读取结束再核对已读附件和页面列表。下载器取得的签名地址不作为附件资料交给模型。

`native-page-files.cjs` 将 AI 区块的原生附件转交同一解析器，无需额外的工作区 API Key：使用当前登录账号读取所选页面/记录的附件块，以块权限指针调用已审核的 `getSignedFileUrls`。会话桥限制一个当前工作区 block 指针，不接受其他工作区、thread 指针或混入参数；取到 HTTPS 地址后使用不带原生会话的下载器。AI 区块生成结束仍复核原始来源及权限，不因解析附件而取得任何页面写入权限。接口字段依据 [36332 的原生文件读取](https://app.notion.com/_assets/36332-65bbf13dccea64ab.js) 及 [38064 的附件预览](https://app.notion.com/_assets/38064-dedcc4138e3e886e.js)，没有猜测新的签名 API。

未支持格式在页面来源中标记 `body_available=false`，不下载二进制；直接要求读取此附件时明确失败。文档中的链接、正文命令、其他记录及任意历史远程附件不会因此自动展开。研究中的附件工具继续受所选页面/数据库范围约束；仅网页研究不启用该工具。图片结果是 OCR 文字，音视频结果是音轨逐字稿，不能冒充画面理解。

## 已授权的具体行为

用户在 Notion 客户端聊天中主动上传支持的文档并发送问题后，在本机解析该文件，将必要文字、表格单元格或 PDF 文字层、文件名和位置随问题发送给**已配置的 DeepSeek**。这可能包含真实业务资料。后续同一账号、工作区和对话中的续问可重新读取该对话附件；停止或解析失败不继续调用模型。

上传入口使用本机存储中可验证归属的文档；新增页面附件入口只读取本轮所选页面内的必要文件块，不跟随文档中的指令读取其他页面、技能或连接器。聊天状态保存附件或引用标识，报告和任务摘要可引用文件内容，不额外保存整份解析正文或签名网址。不修改 Notion 页面，不运行宏、文档脚本或表格公式。

当前与历史附件输入总计最多 8 个文件、24 MiB、240,000 个解析资料字符；当前附件超限要求拆分，不静默丢弃。预算不足的较早附件明确标记省略。附件资料单独标记为数据，用户的实际问题保持为最后的用户任务；压缩与只读协作保留资料标记，文件正文或模型生成的子任务中的“当前页面”等文字不能触发额外自动页面读取。原生图片仍走既有 Flash 图片链路，纯文字文档可用于 Flash 或 Pro；Pro 下当前消息包含图片时保留既有拒绝行为。

## 已完成的本地内核

- `document-parser.cjs` 在独立 Node 线程解析，最多 2 项并行、16 项等待、64 MiB 等待字节；每项默认 10 秒，包含等待时间，解析线程不继承应用环境或预载参数。V8 老生代 256 MiB、年轻代 16 MiB、栈 4 MiB；单文件最大 16 MiB。解析不调用网络。
- `document-zip.cjs` 只在内存读取 OOXML 部分，不落盘解压。核对 CRC、目录与本地头、数据描述符、偏移及重叠；拒绝加密、ZIP64、越界、路径穿越、符号链接、大小写冲突和重复部分。最多 2,048 个条目、32 MiB 声明展开大小，单次读取部分最多 8 MiB。
- `document-xml.cjs` 核对 XML 格式、命名空间、深度和节点数，拒绝 DTD/自定义实体；不加载外部关系。正文支持 UTF-8 和带 BOM 的 UTF-16，不把二进制或损坏编码当作正常文字。
- DOCX 保留段落、表格单元格、实际引用的页眉/页脚和脚注/尾注；删除的修订文字不恢复。数学公式仅提取文字，自动编号、版式、图像和嵌入对象不冒充已渲染内容。
- XLSX 保留工作表名称、可见/隐藏状态、行号、单元格地址、共享字符串、合并范围和公式缓存。包含隐藏工作表并明确标注。保留数值原文和格式；可识别的日期补充 1900/1904 日期系统解释，不推断时区。公式缓存缺失会标明；共享/数组/数据表公式保留元数据并说明未展开。宏、批注、图表和外部链接不执行或展开。
- PDF 读取每页文字层，最多 200 页、200,000 字符；保留页码并支持 ToUnicode 及预定义中文 CMap。静态字体和 CMap 随源码提供，PDF.js 6 的 BinaryDataFactory 只读取这些固定资源，不从网络取得。扫描件没有可读文字层时明确失败；部分页面没有文字层时标记不完整。没有 OCR、图像识别或版式渲染。
- CSV/TSV 保留单元格与换行，识别引号转义，公式样式的单元格仍是普通数据；JSON 必须语法有效。单个文件的结构化结果最大 240,000 字符，超限不返回“完整”结果。
- `local-document-uploads.cjs` 已接入桌面 create/PUT/complete/getFileContentURL 路由。提供同账号/工作区/对话的单次上传令牌、大小核对、不可覆盖保存、SHA-256、幂等完成回执、恢复读取及限时下载 URL。最多 8 项/32 MiB 待上传、30 分钟有效；文件以程序生成的 UUID 命名，文件名不构成路径。已知本地文档丢失或损坏时明确失败，不回退为远程 Notion 图片读取。
