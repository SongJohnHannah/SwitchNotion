# 原生聊天文档附件接口

2026-10-28。范围仅限 Notion 客户端 AI 聊天。本任务保留已正常工作的 Mac 运行、登录、签名、图片和音频流程；采集模块由另一任务验收。

## 当前状态

已接通原生侧栏聊天，以及浮动 writer 的本地上传、解析、模型资料输入、文件下载和重启续问。解析器支持 TXT、Markdown、CSV、TSV、JSON、文字型 PDF、DOCX 和 XLSX；浮动框仍遵守原生上传菜单可接受的类型，不强行打开其他附件功能。实际桌面路由及真实 DeepSeek 的新合成文档验收通过；原生窗口内的文件芯片、上传操作与下载控件仍待手工验收。现有图片通道保留原样；Notion 页面文件块和任意旧远程附件链接不自动读取。

模型接线最初因原授权只覆盖合成资料被自动审批拒绝。用户随后明确回复“允许按此范围接入上传文档正文”，本接口所述范围的授权已经解决，`native-attachments.cjs`、上传路由及 Agent 上下文接线已写入。该授权不覆盖个人指令、技能或研究模式的工作区正文。

## 已授权的具体行为

用户在 Notion 客户端聊天中主动上传支持的文档并发送问题后，在本机解析该文件，将必要文字、表格单元格或 PDF 文字层、文件名和位置随问题发送给**已配置的 DeepSeek**。这可能包含真实业务资料。后续同一账号、工作区和对话中的续问可重新读取该对话附件；停止或解析失败不继续调用模型。

此接线仅使用本机聊天上传存储中可验证归属的文档，不自动下载 Notion 页面中的文件块、个人指令、技能页、连接器或其他业务页，不新增远程 Notion 文档正文读取器。原始字节留在平台既有资料目录；聊天状态保存文件标识，报告和任务摘要可引用文件内容，不额外保存完整解析正文或签名网址。不修改 Notion 页面，不运行宏、文档脚本或表格公式。

当前与历史附件输入总计最多 8 个文件、24 MiB、240,000 个解析资料字符；当前附件超限要求拆分，不静默丢弃。预算不足的较早附件明确标记省略。附件资料单独标记为数据，用户的实际问题保持为最后的用户任务；压缩与只读协作保留资料标记，文件正文或模型生成的子任务中的“当前页面”等文字不能触发额外自动页面读取。原生图片仍走既有 Flash 图片链路，纯文字文档可用于 Flash 或 Pro；Pro 下当前消息包含图片时保留既有拒绝行为。

个人 Instructions/Skills 与研究模式的工作区正文仍分别等待之前的授权；本次文档附件授权不等于允许自动读取这些来源。

## 已完成的本地内核

- `document-parser.cjs` 在独立 Node 线程解析，最多 2 项并行、16 项等待、64 MiB 等待字节；每项默认 10 秒，包含等待时间，解析线程不继承应用环境或预载参数。V8 老生代 256 MiB、年轻代 16 MiB、栈 4 MiB；单文件最大 16 MiB。解析不调用网络。
- `document-zip.cjs` 只在内存读取 OOXML 部分，不落盘解压。核对 CRC、目录与本地头、数据描述符、偏移及重叠；拒绝加密、ZIP64、越界、路径穿越、符号链接、大小写冲突和重复部分。最多 2,048 个条目、32 MiB 声明展开大小，单次读取部分最多 8 MiB。
- `document-xml.cjs` 核对 XML 格式、命名空间、深度和节点数，拒绝 DTD/自定义实体；不加载外部关系。正文支持 UTF-8 和带 BOM 的 UTF-16，不把二进制或损坏编码当作正常文字。
- DOCX 保留段落、表格单元格、实际引用的页眉/页脚和脚注/尾注；删除的修订文字不恢复。数学公式仅提取文字，自动编号、版式、图像和嵌入对象不冒充已渲染内容。
- XLSX 保留工作表名称、可见/隐藏状态、行号、单元格地址、共享字符串、合并范围和公式缓存。包含隐藏工作表并明确标注。保留数值原文和格式；可识别的日期补充 1900/1904 日期系统解释，不推断时区。公式缓存缺失会标明；共享/数组/数据表公式保留元数据并说明未展开。宏、批注、图表和外部链接不执行或展开。
- PDF 读取每页文字层，最多 200 页、200,000 字符；保留页码并支持 ToUnicode 及预定义中文 CMap。静态字体和 CMap 随源码提供，PDF.js 6 的 BinaryDataFactory 只读取这些固定资源，不从网络取得。扫描件没有可读文字层时明确失败；部分页面没有文字层时标记不完整。没有 OCR、图像识别或版式渲染。
- CSV/TSV 保留单元格与换行，识别引号转义，公式样式的单元格仍是普通数据；JSON 必须语法有效。单个文件的结构化结果最大 240,000 字符，超限不返回“完整”结果。
- `local-document-uploads.cjs` 已接入桌面 create/PUT/complete/getFileContentURL 路由。提供同账号/工作区/对话的单次上传令牌、大小核对、不可覆盖保存、SHA-256、幂等完成回执、恢复读取及限时下载 URL。最多 8 项/32 MiB 待上传、30 分钟有效；文件以程序生成的 UUID 命名，文件名不构成路径。已知本地文档丢失或损坏时明确失败，不回退为远程 Notion 图片读取。

## 浮动 writer 的附件接入

公开上传工具 `UISpacePermissionGroupToken-cbfe38c487518b52.js` 调用 `getUploadFileUrlForAssistantChatTranscriptUpload`，使用 multipart POST；上传生产者 `38064-dedcc4138e3e886e.js` 会随机化传输文件名，再由原生步骤保留实际显示名。原生 `attachment` 使用 `fileUrl/fileName/contentType` 和 `metadata.attachmentSource`；`computer-file` 可表示用户上传，也可表示 Agent 下载，不能仅凭步骤类型认定有读取授权。

`local-inline-documents.cjs` 只接管支持文档的当前账号本地 writer 上传，绑定工作区和对话。创建本地草稿不会创建远程页面或调用 Notion 托管 AI；成功的文件回执由同一文档存储核对大小与 SHA-256。multipart 表单最多只有固定标记和一个文件，限额、超时、跨来源、重放及并发检查不会放开原有图片上传。下载用仅在本机协议处理器内有效的随机引用能力地址；引用保存在私人本地历史，模型只收到文档资料及位置，不收到该地址。

PDF/CSV/文本的原生处理消费模块 175529 位于 `51103-3324439f61c31e75.js`，SHA-256 `4bfc72339b57ee5fddbd9428afa5f2b5060ff4f190501ce79e47488dc254f924`。精确审核的 `compat/inline-documents.cjs` 仅对本地地址加适配标识，并将本地处理元数据交回原生转换函数，避免订阅不存在的托管任务。普通服务器/图片回执保留原流程。未审核版本返回明确错误；附件适配失败不改变既有录音就绪状态，也不触发录音准备。
